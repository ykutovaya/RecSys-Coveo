# Сессионные рекомендации на данных Coveo

Проект рекомендательной системы для интернет-магазина: по просмотрам и поиску в текущей анонимной сессии подобрать товары, которые пользователь может купить до её завершения.

Проект находится на этапе проектирования. Подготовлены спецификация, техническое задание и шаблон паспорта запуска. Программной реализации, обученных моделей и измеренных результатов пока нет.

## Задача и данные

На каждом запросе система должна отобрать до 300 кандидатов и вернуть до 20 различных допустимых товаров. Для обучения используются последующие покупки той же сессии; события после момента запроса не должны попадать в признаки.

Источник данных — Coveo SIGIR eCom Data Challenge:

- `browsing_train.csv` — события взаимодействия с товарами;
- `search_train.csv` — поисковые события;
- `sku_to_content.csv` — сведения о товарах и их векторные представления.

Исходные данные в репозиторий не включены.

## Что запланировано

Первая реализация — GCS+Rk: граф связей между товарами, сходство описаний и изображений, поисковый запрос и ранжировщик LambdaMART на LightGBM.

Порядок работ:

1. Подготовить данные, разделить сессии по времени, построить граф и справочники.
2. Реализовать отбор кандидатов, расчёт признаков и обучение ранжировщика.
3. Воспроизвести выдачу на отладочном периоде `C_smoke`, проверить расчёты и получить первый отчёт. Периоды выбора модели, калибровки и итоговой оценки на этом этапе остаются закрытыми.
4. Реализовать сервис со сроком ответа, резервной выдачей и восстановлением состояния; провести нагрузочные испытания и итоговую историческую оценку по отдельному плану.

Нейросетевые модели и приближённый поиск — последующие расширения. Реальный A/B-эксперимент не входит в первый запуск.

## Запуск

Запустить рекомендательную систему пока нельзя: исполняемого кода и файла зависимостей нет. Команды из ТЗ описывают будущий интерфейс, а не доступные команды.

### Сборка математической спецификации

Нужен дистрибутив TeX с XeLaTeX, пакетами из преамбулы документа (включая `polyglossia`) и шрифтами Times New Roman, Arial и Consolas. Из корня репозитория:

```sh
cd documents/math
xelatex -interaction=nonstopmode -halt-on-error coveo_session_recommender_math.tex
xelatex -interaction=nonstopmode -halt-on-error coveo_session_recommender_math.tex
```

Результат — `documents/math/coveo_session_recommender_math.pdf`. Если остаётся предупреждение о необходимости пересборки ссылок, повторите последнюю команду.

## Измеренные результаты

Обучение и оценка на Coveo, автоматические проверки и нагрузочные испытания ещё не выполнены. Значения качества, задержки и потребления памяти не измерены. Числа в спецификации — требования или расчётные примеры, а не результаты проекта.

Основной показатель будущей исторической оценки — `POR_1000`: число сессий с попаданием хотя бы в один впоследствии купленный товар на 1000 подходящих зрелых сессий. Он не измеряет прирост покупок от рекомендаций; для такого вывода нужен отдельный эксперимент с показами.
